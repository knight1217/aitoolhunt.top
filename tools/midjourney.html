📖 How to Use Midjourney

  1. Go to midjourney.com and subscribe (Basic $10/mo is enough to start).
  2. Join Midjourney Discord server OR use the web app at midjourney.com/imagine.
  3. Type /imagine followed by your prompt. Example: '/imagine a cyberpunk city at sunset, neon lights reflecting on wet streets, 8k, cinematic lighting'.
  4. Bot generates 4 variants — click U1-U4 to upscale (enlarge), V1-V4 to create variations of that image.
  5. Add parameters to control output: '--ar 16:9' for widescreen, '--style raw' for realistic, '--stylize 500' for artistic flair.
  6. Reference existing images with '--cref [imageURL]' to match style.
