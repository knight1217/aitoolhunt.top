## The tech stack (zero coding required)

I used nothing but free tools and one dollar:

- **Domain**: $1/year from Spaceship (aitoolhunt.top)
- **Hosting**: GitHub Pages — free, no server to manage
- **Content**: Written by AI, fact-checked by me
- **Design**: Pure HTML/CSS/JS, no frameworks

That's it. No Vercel. No Netlify. No monthly fees. Just a GitHub repo and a domain.

- **Side-by-side comparisons** — Compare any two tools on features, pricing, and pros/cons

## The one feature people actually use: Comparisons

I built it because every time I searched "X vs Y" on Google, I got 10 SEO-spam articles that took forever to find a straight answer.

## What I learned building with zero budget

**1. You don't need to be a developer.** AI wrote most of the code. I just directed it.

**2. Free tools are good enough.** GitHub Pages handles traffic fine. The domain cost me less than a coffee.

**3. Honesty beats SEO tricks.** People can smell affiliate links from a mile away. A clean, genuine resource stands out.

**4. Ship first, polish later.** The first version had 16 tools and looked terrible. I launched anyway. It's at 200+ now and getting better every day.
